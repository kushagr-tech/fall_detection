Place these two files here before building the app:

  har_model.ptl     — TorchScript lite model exported by:
                        cd har_pipeline && python export_mobile.py

  har_labels.txt    — class labels, one per line, generated by same script.

Both files are produced automatically when you run:

    cd har_pipeline
    python pipeline.py --data_dir data/raw   # train
    python export_mobile.py                  # export to this folder

The InferenceEngine.kt will find them at runtime via context.assets.open().
If har_model.ptl is missing, the app will still run but inference will fail
silently (the "LIVE DETECTION" panel will show nothing).
